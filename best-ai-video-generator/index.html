How to call any of them: submit, poll, retrieve

This is the part that is the same for all twelve, and the part the rest of the first page for this keyword does not cover — a scan of the four ranking pages we read for this article turned up no endpoint, no API key and no async task handling anywhere in 8,513 words of text.

Authentication is one header, and the key comes from the console. The full lifecycle is documented in Modellix’s REST API guide, and it starts like this:

Every model call on that host is an asynchronous task, so the response is not your video — it is a handle for it:

Keep the task_id and poll the URL the response hands you; the task-result endpoint reference covers the full response. When status flips to success, the assets arrive under result.resources, each with its own url, type, width, height, format and role. A minimal Python loop — the shape is the same for all twelve models, only the body changes:

Three details worth knowing before you build on this. Generated assets are retained for seven days, so copy them to your own storage as part of the pipeline rather than after it. Polling is optional: send an X-Webhook-URL header on the submit call and the platform posts the same payload to your HTTPS endpoint when the task reaches a terminal state, retrying on 429 and 5xx and not retrying on 4xx — which is the version you want in production. And image inputs go through a separate File API (POST /api/v1/media/files, multipart/form-data with the field named file), which returns a URL you pass into the model’s image field; uploads are not billed, but they are capped at 16 MB per file and about seven days of retention.

Errors are worth reading once rather than logging forever: 400 means fix the parameters, 401 a bad key, 402 an empty balance, 404 a task or model that does not exist, 429 you are over concurrency or RPM — check X-RateLimit-Reset and back off — and 500/503 are the two codes worth retrying with exponential backoff. Concurrency and RPM scale with your funding tier rather than being a fixed number, and the entitlements page has the current table.

The twelve models, one by one

Each entry gives you the route, the price read on September 15, 2026, the parameters its schema actually accepts, and one constraint that is worth knowing before you commit. The request bodies are transcribed verbatim from each model’s published OpenAPI schema — the same source as the parameter lists — and are meant to be run against your own key; they have not been executed against a live account for this page, so treat the first one as a smoke test of your own credentials rather than a verified call.

1. Vidu Q3 Pro T2V — vidu/viduq3-pro-t2v

Vidu’s premium cinematic text-to-video route, and the cheapest floor on this list at $0.0450~$0.1200 per second. The schema is deliberately small: prompt-only, with duration, aspect ratio, resolution and an optional seed for reproducibility.

Required: prompt. Optional: duration, aspect_ratio (16:9, 9:16, 1:1, 3:4, 4:3), resolution (540p, 720p, 1080p), seed. Constraint: the badge on this route publishes a range, not a unit price, and resolution is one of the parameters that moves you along it — treat $0.0450/second as the price of your cheapest acceptable settings, not of your intended ones. Vidu’s own model page also states that this route does not support automatic background music and points you at Q3 Turbo T2V if you need fast previews. Model page

The cheapest floor on the shortlist, read from its model page on September 15, 2026. The badge publishes a range rather than a unit price; resolution (540p, 720p or 1080p) is one of the parameters that decides where on it you land.

2. Wan 3.0 T2V — alibaba/wan3.0-t2v

Alibaba’s Wan 3.0 is the longest-clip option here alongside Seedance 2.5: 2 to 30 seconds in a single call, at $0.0500~$0.2000 per second. It is also unusual in accepting three different starting points — a text prompt, an uploaded file, or a public webpage link — for grounding the generation.

Required: one of prompt, file_url or link_url — this route will not accept an empty body. Optional: resolution (480P, 720P, 1080P), ratio (16:9, 4:3, 1:1, 3:4, 9:16), duration (2–30), audio (defaults to true), seed. Constraint: audio is on by default, so if you want a silent file you have to turn it off explicitly. Alibaba documents the same route family in its Wan text-to-video API reference if you want the provider’s own view of the parameters. Model page

3. PixVerse V6 T2V — pixverse/v6-t2v

PixVerse V6 publishes eight aspect ratios — including the 2:3/3:2 pair that only Grok Imagine Video also carries here — and is one of two routes with a multi-clip toggle (generate_multi_clip_switch; Kling V3’s multi_shot is the other). It is priced at $0.0500~$0.2300 per second.

Required: prompt, aspect_ratio, duration, quality — four required fields, matched on this list only by MiniMax H3. aspect_ratio accepts 16:9, 9:16, 1:1, 3:4, 4:3, 2:3, 3:2, 21:9; quality maps to 360p, 540p, 720p or 1080p; duration is an integer from 1 to 15. Optional: seed, generate_audio_switch, generate_multi_clip_switch. Constraint: because duration and quality are mandatory, there is no “just send a prompt” path here — a first smoke test needs four parameters, not one. Model page

4. Hailuo 2.3 T2V — minimax/hailuo-2.3-t2v

Hailuo 2.3’s published range is a narrow one — $0.0504~$0.0738 per second, a 1.46× spread — and its 1080P tier at $0.0738 is the lowest 1080p price of the twelve. MiniMax positions this model for human performance and stylised aesthetics rather than general scenery.

Required: prompt. Optional: prompt_optimizer (defaults to true), fast_pretreatment, duration, resolution. Constraint: duration is not a range — it accepts 6 or 10 seconds and nothing in between — and the two parameters interact: the schema states it twice, that a 10-second clip only supports 768P. A 1080P Hailuo clip is a 6-second clip. Model page

5. Seedance 2.0 Fast T2V — bytedance/seedance-2.0-fast-t2v

ByteDance’s faster Seedance variant, at $0.0600~$0.1200 per second — the cheapest way onto the Seedance family. It also carries more runtime knobs than most: a camera lock, an audio toggle, a last-frame return and an execution expiry.

Required: prompt. Optional: ratio (16:9, 4:3, 1:1, 3:4, 9:16, 21:9, adaptive), resolution (480p or 720p), duration (4–15), seed, camera_fixed, generate_audio, execution_expires_after, return_last_frame. Constraint: the fast variant caps at 720p — if 1080p is a requirement, this is the wrong sibling and Seedance 2.5 is the one you want. ByteDance’s own ModelArk documentation is the provider-side entry point for this family. Model page

6. Kling V3 T2V — kling/kling-v3-t2v

Kling V3 is one of only two routes here that reach 4k, priced at $0.0672~$0.3360 per second — a 5× spread between its 720p/no-audio tier and its 4k tier. It documents native synchronised audio and multi-shot generation directly from text.

Required: prompt. Optional: audio (native or off), multi_shot, resolution (720p, 1080p, 4k; defaults to 720p), aspect_ratio (16:9, 9:16, 1:1; defaults to 16:9), duration (3–15; defaults to 5). Constraint: the aspect-ratio enum is only three values wide — no 4:5 or 21:9 crop here. Kling publishes its own developer API documentation if you need the provider-side reference. Model page

Kling V3’s badge, captured September 15, 2026. Its published range spans 5× between floor and ceiling, and the two parameters that move you along it are resolution (720p, 1080p, 4k) and audio (off or native).

7. MiniMax H3 T2V — minimax/minimax-h3-t2v

MiniMax H3 is the second MiniMax entry and the more demanding of the two by design, at $0.0800~$0.1300 per second with a 1.62× spread.

Required: prompt, duration, resolution, ratio — all four. duration runs 4–15, resolution is 768P or 2K, ratio accepts 21:9, 16:9, 4:3, 1:1, 3:4, 9:16. Constraint: the schema marks all four as required even though it also lists a default for three of them, so send all four rather than relying on a fallback. MiniMax’s pay-as-you-go pricing page is the provider-side reference for this family. Model page

8. Grok Imagine Video — xai/grok-imagine-video

xAI’s text-to-video route is one of the two most predictable prices on the list — $0.0840~$0.1080 per second, a 1.29× spread, tied with HappyHorse 1.1 — and the simplest schema: prompt, duration, aspect ratio, resolution.

Required: prompt. Optional: duration (1–15, defaults to 8), aspect_ratio (1:1, 16:9, 9:16, 4:3, 3:4, 3:2, 2:3), resolution (480p or 720p). Constraint: 720p is the ceiling. Price stability is real, but it is bought with a resolution cap that the price itself does not tell you. Model page

9. SkyReels T2V — skywork/skyreels-t2v

Skywork’s SkyReels route spans $0.0960~$0.4200 per second and is unusual in exposing an explicit quality-versus-speed switch rather than hiding it behind a resolution enum.

Required: prompt. Optional: duration (3–15, defaults to 5), aspect_ratio (16:9, 4:3, 1:1, 9:16, 3:4), resolution (480p, 720p, 1080p), mode (fast or std), sound, prompt_optimizer. Constraint: mode is a separate axis from resolution, so a 1080p fast run and a 1080p std run are different jobs at the same nominal resolution — pin both if you are comparing cost between runs. Seedance 2.5 is the current ByteDance flagship: 4 to 30 seconds, up to 1080p, native audio, and a choice of mp4 or mov output, at $0.1030~$0.5690 per second — a 5.52× spread, the widest on this list.

11. HappyHorse 1.1 T2V — alibaba/happyhorse-1.1-t2v

Alibaba’s HappyHorse 1.1 is the newest route on the list and one of the two tidiest to forecast, a 1.29× spread: $0.1400~$0.1800 per second, 720P or 1080P, 3 to 15 seconds.

12. Veo 3.1 T2V — google/veo-3.1-t2v

Google’s Veo 3.1 is the most expensive route on the shortlist at $0.3600~$0.5400 per second, and the only one of the twelve whose schema documents both a personGeneration policy and a separate negativePrompt field. It reaches 4k with natively synchronised audio.

What a per-second price does and does not tell you

It does not tell you the top of the range. Of the 112 video routes in the catalogue, 88 publish a range rather than a single number, and the twelve here are no exception: only the price floor is a fixed, checkable quantity. The ceiling moves with the parameters you send — resolution, duration, mode — which is why Kling V3’s ceiling is 5× its floor and Seedance 2.5’s is 5.52×. A budget built on floor prices is a budget for minimum quality settings.

It does not tell you what a clip costs. Per-second is a unit rate, and unit rates multiply. Worked at the floor price of each route, and rounded to the cent:

Cost of one minute of generated video at each route’s listed floor price, September 15, 2026. Arithmetic on published numbers: floor price × 60. It is a floor, not a forecast — the ceiling is up to 5.5× higher on some of these routes.

One minute of output costs $2.70 on Vidu Q3 Pro’s floor and $21.60 on Veo 3.1’s — the same eight-fold gap you see per second, unchanged by scale. That is the number to put in front of whoever owns the budget, because “per second” means nothing to them and “eight times” does.

It does not tell you what the cheapest thing in the catalogue is. The $0.0050 floor belongs to digital-human routes, not to a general-purpose generator, and the $1.4400 ceiling belongs to a video-editing route. Both are real, both are in the model index, and neither is a text-to-video price. Quoting either as “the price of AI video” is the most common way this data gets misused.

What it does tell you, reliably: the price of the call you are about to make. Every route here is billed per second of output rather than per month or per credit, which means the cost of a test is bounded and small — Hailuo 2.3’s shortest clip is six seconds for about $0.30, and Veo 3.1’s is four seconds for about $1.44. That is the actual argument for pricing a shortlist by trial rather than by review: you can afford to run the same prompt across all twelve and look at the files.

One key across the nine providers behind these routes: what it changes, and what it does not

Nine providers means nine sets of credentials, nine balances, nine error formats and nine async lifecycles if you integrate them separately. Aggregating them means one API key, one bill and one submit-poll-retrieve contract, and switching a model becomes a URL and a request body rather than a new vendor integration — which is the same argument we made in running multiple video models on one API. That is a workflow claim about the shape of your integration, and it is the only claim we are making.

To be explicit about what that is not: this is not a claim that Modellix is the cheapest way to reach any of these twelve models. Several of them are sold directly by the providers that make them, at prices this page does not attempt to undercut or compare. This is also not a claim about which model looks best — we did not run that test, and a shortlist ranked by anything other than price would need one. And it changes nothing about the models themselves: the resolution caps, duration ceilings and parameter requirements documented in the twelve entries above are the provider’s, not ours, and they travel with the model whichever route you call it through.

The one place the aggregation argument becomes concrete rather than abstract is the log. A per-second price is only useful if you can see what you actually spent, and the request-logs endpoint returns the billed amount per task alongside the model, the timestamp and the duration — so a cost-per-usable-clip number is arithmetic on your own data rather than an estimate from a pricing page.

Frequently asked questions

Is there a 100% free AI video generator?
Not on this list, and not for callable API access. None of the twelve routes has a free tier; the catalogue is pay-as-you-go with no monthly minimum, and new registrations no longer receive a signup credit — trial credit is requested by email. The genuinely free path to AI video is running an open-weight model on your own hardware, which trades the API bill for a GPU bill and an operations bill. If your requirement is literally zero dollars, self-hosting is the answer and this page is not.

Can ChatGPT generate videos for free?
That question is about a consumer product, and nothing here prices it. What this data can tell you is narrower and checkable: OpenAI is not one of the nine providers behind the 112 video routes in this catalogue, so if you want a callable video model, the names above are the ones with published per-second prices to compare.

How much does one clip actually cost?
Multiply the listed per-second price by the duration you request. Worked at the floor prices read on September 15, 2026, and at a duration each route actually accepts: Kling V3 at 5 seconds is about $0.34 and Seedance 2.5 at 5 seconds about $0.52, while Hailuo 2.3 allows only 6 or 10 seconds — its shortest clip is about $0.30 — and Veo 3.1 allows only 4, 6 or 8, so its shortest is about $1.44 and its 8-second 1080p clip about $2.88. At each route’s ceiling it costs more — up to 5.5× more on Seedance 2.5 — because the ceiling applies when you ask for higher resolution or longer output.

Which model produces the most realistic video?
Realism is not a parameter, so no schema can answer this and we are not going to imply a test we did not run. What the schemas do give you is the levers that correlate with it: resolution, duration and native audio. Our practical suggestion is the one this pricing model makes cheap — run the same prompt across three or four candidates, look at the files, and let the result decide. A comparison built on somebody else’s screenshots is a comparison built on their prompt.

Why do the prices show a range instead of one number?
Because the parameter that changes the work changes the price. 88 of the 112 video routes in the catalogue publish a range rather than a flat figure, and for the twelve above, resolution, duration and the mode switch are what move you along it. The floor is reachable — at the cheapest settings the route allows. If you are budgeting, budget the ceiling for the settings you actually intend to send.

Do I need a separate account for each model?
Not through this route. One key reaches all nine provider brands behind these video routes — the count on the model pages, not the wider catalogue’s brand total — and every model on the list is called with the same submit-poll-retrieve pattern shown earlier in this article; what changes between them is the URL and the body. The twelve models are also available individually from the providers that make them, which is a legitimate choice if you only ever need one.

Is there an app, or does this work from a phone?
No. There is no consumer app for these routes — they are REST endpoints, and the output lands on a URL that expires after about seven days unless you store it. If you want a phone app that generates video from a prompt, you want a different product than an API aggregator.
