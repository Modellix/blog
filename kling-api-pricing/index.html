Kling AI API Pricing and Model Selection in 2026

April 27, 2026
Kling API Guide Pricing Video Generation
Modellix Team Official
Summary

Kling V1 and V2 model routes are no longer in the Modellix catalog. This guide maps the live V3, O1, and Omni routes to video tasks and shows a current API request.

As of September 24, 2026, Modellix’s Kling provider catalog lists V3, O1, Omni, and utility routes. Old V1 and V2 model pages such as kling-v2.5-turbo-t2v redirect to the general model catalog, and their public schemas return 404. Do not build a new integration from an older Kling price table or copy a V2 request path from an archived guide.

Choose a live Kling route by input and output

The routes below were checked against their Modellix public schema pages on September 24, 2026. The linked model pages show current prices; the prices and parameter sets can change independently.

Job Route Why choose it
General text-to-video, up to 15 seconds with optional native audio and 4K kling/kling-v3-t2v Default when you start with a prompt and need the widest V3 output range.
Fast text-to-video iteration kling/kling-v3-turbo-t2v Prioritizes turnaround; its public schema supports 720p and 1080p but has no audio field.
Narrative text-to-video with consistency control kling/kling-v3-omni-t2v Supports V3 multi-shot planning and native audio.
Physics-heavy text-to-video kling/kling-video-o1-t2v Reasoning-focused route, limited to 10 seconds and no native audio.
Animate one still image kling/kling-v3-i2v Single-image path with an optional ending frame.
Animate several visual references kling/kling-v3-omni-i2v Accepts an images array for reference-led motion.
Edit source video kling/kling-v3-omni-video Accepts source videos and optional image references.

Do not reuse one payload across these paths. For example, V3 T2V has audio and multi_shot, Turbo T2V has neither in its public schema, and O1 T2V accepts audio: "off" only. Read the route’s Schema when you switch models.

How to estimate Kling API cost

Modellix displays video prices per generated second, often as a range. On September 24, the provider page showed kling/kling-v3-t2v at $0.0672 to $0.3360 per second, kling/kling-v3-turbo-t2v at $0.0896 to $0.1120 per second, and kling/kling-video-o1-t2v at $0.0672 to $0.0896 per second. These are ranges across configurations, not quotes for one identical job.

For a budget, select the exact route, resolution, audio setting, and duration on its model page. Multiply its applicable per-second rate by output seconds, then allow for retries. A five-second clip at $0.0672 per second is $0.336 for one accepted generation; five attempts at that setting cost five times as much. If output yield matters, run the same prompt through two candidates and count usable clips before picking a route by list price.

Submit a Kling V3 text-to-video job

The current V3 T2V schema names https://api.modellix.ai/api/v1/kling/kling-v3-t2v as the POST URL. It requires prompt; the settings below are valid schema values. Keep the API key server-side.

The submission returns a task_id and a get_result.url. Poll that returned URL for the result rather than assuming the initial POST contains a finished video. The Modellix API documentation covers authentication, task retrieval, and errors. The model schema is the source for request fields; an old V2 example is not a safe template for V3 or O1.

Which route should you try first?

Start with V3 T2V for a prompt-only clip or V3 I2V if you have a first frame. Use Omni when references or scene continuity drive the result, and O1 when the motion or physical sequence is the hard part. Turbo is useful for fast iteration, but compare the price badge for your exact settings before assuming it costs less. For portrait speech, kling/kling-avatar is a separate audio-driven route.

Run one job in the model page’s Playground, then use the API key for a repeatable workload. Modellix uses pay-as-you-go billing; there is no signup credit to assume in the cost calculation.
