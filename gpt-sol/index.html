GPT-6 Sol Is Now Available on Modellix

September 24, 2026
OpenAI LLM API Model Launch
Modellix Team Official
Summary

GPT-6 Sol is available as openai/gpt-6-sol. Use one Modellix key to compare the GPT-6 tiers on the same task, then keep routine difficult work on Sol and escalate only when a run needs more reasoning.

GPT-6 Sol is officially live on Modellix under the model ID openai/gpt-6-sol.

OpenAI released Sol and Luna on September 22, 2026, about three weeks after the GPT-6 Astra flagship. Sol is the middle tier: it carries Astra’s training into a faster, cheaper model for everyday difficult work. Call it through the Modellix LLM gateway with one Modellix API key, then change the model ID to compare it with Astra or Luna.

If your team runs agents across business tools, reviews code changes, or drafts long documents that someone has to check, Sol is the GPT-6 model to test first.

What’s New in GPT-6 Sol

Astra’s training at a mid-tier price

OpenAI says Sol was trained with methods similar to GPT-6 Astra, so the same work on professional tasks, factuality, coding, computer use, and alignment carries over. Astra still leads on the most demanding projects. Sol is positioned for the difficult work that makes up most of a normal week.

Half the price of GPT-5.6 Sol

OpenAI cut Sol’s API price by 50% against GPT-5.6 Sol: input drops from $4 to $2 per million tokens, and output from $20 to $10.

Agent and coding results

On AutomationBench 1.0.6, which runs end-to-end business workflows across 47 tools, GPT-6 Sol at xhigh effort scores 33.2% at $0.27 per task. That is ahead of Claude Opus 5 at max effort (26.9%) and GPT-6 Astra at low effort (30.3%). On DeepSWE 1.1, Sol at max effort scores 68.8%. These are OpenAI’s published figures, so treat them as vendor benchmarks and check them on your own workload.

Fewer factual mistakes

On OpenAI’s internal factuality evaluation, built from de-identified conversations where users flagged an error, Sol makes about half as many mistakes as GPT-5.6 Sol.

1.05M context, text and image in

On Modellix, Sol takes text or image input, returns text, and accepts up to 1.05M tokens of context. Inputs above 272K tokens are billed in a second Input Context tier, which matters if you plan to send whole repositories or long contracts in one call.

What Can You Build with GPT-6 Sol

A product team could add a release manager panel to its publishing workflow. Sol turns merged changes into customer-facing notes and flags claims a reviewer cannot verify from the changelog, giving a product manager a draft to approve instead of asking them to write every update from scratch. The model should not invent missing details; the review step stays with the person responsible for the release.

We ran that step through the gateway using openai/gpt-6-sol and the three-line changelog in the request below. Sol returned three release notes that stayed inside the source text: uploads now retry on a 429 response, a webhook is available for the task.completed event, and the SDK dependency moved to 2.4.1. It did not invent a benefit or a version number. It also flagged two gaps a reviewer would want closed before publishing: the changelog does not say which SDK was updated, and it does not specify retry timing or limits. The call took about eight seconds.

That is one small, verifiable task, not a benchmark. To judge Sol for your own pipeline, run ten real releases through it and through your current model with the same prompt, then compare unsupported claims, missed changes, and cost per run.

Start with Sol and Escalate Only When Needed

Point your OpenAI-compatible app to https://llm.modellix.ai/v1 and use one Modellix API key. Start release-note drafts and everyday agent tasks on openai/gpt-6-sol; move difficult cases to Astra or routine, high-volume requests to Luna. Compare the tiers with one credential, then send each task to the model that fits your quality and cost targets.

If a release also needs a campaign visual, the same Modellix key works with GPT Image 2 through the media API. Image and video generation use a separate host and finish asynchronously; your GPT-6 request stays on the synchronous LLM gateway. Modellix also supports OpenAI and Anthropic request protocols, so compatible clients can keep their request format while you change the base URL and model ID.

OpenAI’s official API pricing lists GPT-6 Sol at $2 per million input tokens and $10 per million output tokens on Standard short-context requests. At 8,000 input tokens, 8,000 output tokens, and zero cached tokens, that is about $0.096 on OpenAI. This benchmark uses the same billed token counts on Modellix, stays within the 272K input-context tier, and excludes Batch, Flex, and Fast pricing.
