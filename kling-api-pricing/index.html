Kling API Pricing: Per-Second Cost for V3, Turbo, O1 & Omni

April 27, 2026
Video Generation Pricing API Guide Kling
Modellix Team Official
Summary

Kling V3 on Modellix costs $0.0672 to $0.336 per second. See every live Kling route priced by resolution and audio, what a clip costs, and which route to try first.

Kling V3 on Modellix costs $0.0672 to $0.336 per second of generated video, billed per second with no subscription. The rate depends on three things: the route, the resolution, and whether you turn on native audio.

The cheapest setup is 720p with audio off. 4K costs the same with or without audio. Price the exact route, resolution, and audio setting before you budget, because the same 10-second clip can cost $0.67 or $3.36.

Kling 4.0 is not on the API yet. For its confirmed specs and our per-second estimate, see Kling 4.0: release date, pricing, and what to use now.

Choose a Live Kling Route by Job

Job Route Why choose it
General text-to-video, up to 15 seconds with optional native audio and 4K kling/kling-v3-t2v Default when you start with a prompt and need the widest V3 output range.
Fast text-to-video iteration kling/kling-v3-turbo-t2v Prioritizes turnaround; its public schema supports 720p and 1080p but has no audio field.
Narrative text-to-video with consistency control kling/kling-v3-omni-t2v Supports V3 multi-shot planning and native audio.
Physics-heavy text-to-video kling/kling-video-o1-t2v Reasoning-focused route, limited to 10 seconds and no native audio.
Animate one still image kling/kling-v3-i2v Single-image path with an optional ending frame.
Animate several visual references kling/kling-v3-omni-i2v Accepts an images array for reference-led motion.
Edit source video kling/kling-v3-omni-video Accepts source videos and optional image references.

Do not reuse one payload across these paths. For example, V3 T2V has audio and multi_shot, Turbo T2V has neither in its public schema, and O1 T2V accepts audio: "off" only. Read the route’s Schema when you switch models.

Old V1 and V2 routes such as kling-v2.5-turbo-t2v are no longer in the Modellix catalog, so do not copy a V2 request path from an archived guide.

The POST URL is https://api.modellix.ai/api/v1/kling/kling-v3-t2v. It requires prompt; the other settings below are valid schema values. Keep the API key server-side.

The response returns a task_id and a get_result.url. Poll that URL until the task finishes, then download the video. The API guide covers authentication, task retrieval, and errors, and each model’s Schema tab lists its fields.

Which Kling Route Should You Try First?

Start with V3 T2V for a prompt-only clip or V3 I2V if you have a first frame. Use Omni when references or scene continuity drive the result, and O1 when the motion or physical sequence is the hard part.

Turbo is useful for fast iteration, but compare the price badge for your exact settings before assuming it costs less. For portrait speech, kling/kling-avatar is a separate audio-driven route.

Run one job in the Playground first, then use an API key once the prompt and settings are worth repeating.
