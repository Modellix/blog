Kling 4.0: Release Date, Pricing & What to Use Now

September 29, 2026
AI Video Kling Video Generation
Modellix Team Official
Summary

Kling 4.0 is coming in October with native 30-second generation, 4K HDR, stereo audio, and up to 15 multimodal references. Here is what Kling has confirmed, what is still unknown, and how to build on Kling V3 today.

Kling 4.0 is Kuaishou’s next flagship video model. Kling announced it on September 28, 2026: the full model arrives in October, and a lighter Kling 4.0 Flash is already open to Ultra Yearly subscribers in the Kling app.

The headline change is length. Kling 4.0 generates native 30-second clips, twice Kling V3’s 15-second ceiling, with 4K HDR output, stereo audio, and up to 15 multimodal references.

There is no public API or per-second price yet. Modellix will add Kling 4.0 once its API ships. Until then, the Kling V3 family covers most of the same work, billed per second with no subscription, and this page shows which route to use for what.

Kling V3 is the current generation and is already available on Modellix. Here is how the announced 4.0 specs compare.

The two changes that matter most are length and references. A 30-second native shot removes most of the stitching that short-drama and ad teams do today. Fifteen references make it easier to keep one character, product, or set consistent across a series.

The V3 column comes from the Modellix model docs for kling/kling-v3-t2v and the V3 Omni routes. For V3 prices by resolution and duration, see our Kling 3.0 cost breakdown.

Kling 4.0 Release Date and Access

Kling says the full model launches in October 2026. The exact day has not been announced.

Kling 4.0 Flash went live the same day as the announcement, but only for Ultra Yearly subscribers in the Kling app. Kling has not announced API access for Flash.

Three things are still unpublished: API access, per-second pricing, and model IDs. Keep duration, resolution, and audio configurable in your code, so the 4.0 limits can slot in without a rewrite.

How Much Will Kling 4.0 Cost per Second?

Fair question, and the one most builders ask first. Kling has not published a per-second API price for Kling 4.0 or 4.0 Flash yet. For now, Flash is only in the Kling app, on the Ultra Yearly plan.

What Can You Build with Kling

Kling 4.0’s feature list reads like a brief for serialized video. These are the products it will make easier, and the ones you can start on Kling V3 now.

  • AI short-drama and anime series. Episodes with a recurring character. V3 handles 15-second scenes today; 4.0 doubles the scene length and adds keyframes for tighter storyboards.
  • Product ads from brand assets. Packshots and lifestyle photos as references, turned into short spots. V3 Omni takes references now; 4.0 raises the limit to 15.
  • Localized ad variants. One concept voiced in several languages. 4.0 adds accents and dialects to native audio.
  • Talking-character clips. Mascots or presenters with lip sync, where V3 Turbo is the fast, cheaper draft route.

How to Get Your Pipeline Ready for Kling 4.0

Kling video on Modellix is an async task: submit, poll, then download before the result URL expires. In our runs, result URLs expired seven days after the task completed. Three habits make the 4.0 switch painless:

  1. Read field support per route. Kling V3 accepts audio; V3 Turbo rejects it. Expect 4.0 to add new fields rather than reuse every V3 one.
  2. Treat duration as a setting, not a constant. V3 stops at 15 seconds; 4.0 goes to 30.
  3. Save outputs on completion. Store the MP4 before the result URL expires.
